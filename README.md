## Container Variables
- **ADMIN_TOKEN**: Secret token required to access the protected `/api/admin/config` route (Authorization: Bearer <token>).
- **BIND_ADDR**: Address to bind the Axum server (default: `0.0.0.0:4407`).
- **Volume Mappings:**
  - `/app/config`: Map this directory to inject custom configuration files
  - `/app/data`: Map this directory for persistent data storage
